# Gym Tracker для iPhone

Обёртка над Gym Tracker из Claude, чтобы он работал как настоящее приложение:

- текущее упражнение, подход и **таймер отдыха на экране блокировки и в Dynamic Island**: время идёт само, даже когда телефон спит;
- настоящая вибрация на барабанах и в меню по удержанию;
- экран не гаснет во время тренировки;
- данные те же, что в Claude: приложение открывает твою же страницу.

Сборка идёт на GitHub (см. вкладку **Actions**), готовый `GymTracker.ipa` лежит в **Releases**. Ставится через [SideStore](https://sidestore.io) с обычным бесплатным Apple ID, $99 в год не нужны.

## Установка (один раз, нужен компьютер)

1. На компьютере: **iTunes** с сайта Apple (не из Microsoft Store) и **[iloader](https://github.com/nab138/iloader/releases)**.
2. На айфоне: код-пароль и приложение **LocalDevVPN** из App Store.
3. Подключи айфон кабелем, открой iloader, войди своим Apple ID и выбери **Install SideStore**. Бери самую свежую сборку (0.7.0-alpha или Nightly): в 0.6.4 и старше вход в Apple ID сломан после изменений Apple в сентябре 2026.
4. На айфоне: **Настройки → Основные → VPN и управление устройством** → доверься своему Apple ID. Потом **Настройки → Конфиденциальность и безопасность → Режим разработчика** → включить (телефон перезагрузится).
5. Открой SideStore и войди тем же Apple ID.
6. В SideStore: **Sources → +** и вставь ссылку
   ```
   https://raw.githubusercontent.com/fingercomment-dot/gym-tracker-ios/main/source.json
   ```
   Потом найди там **Gym Tracker** и нажми **Free** / **Install**. Без источника можно и так: скачай `GymTracker.ipa` из Releases и открой его в SideStore через «+» на вкладке **My Apps**.

## Первый запуск

Вставь ссылку на своё приложение в Claude (`https://claude.ai/artifact/…`) и войди в аккаунт Claude. Это нужно один раз.

**Меню приложения:** Настройки → «Приложение для iPhone», или просто встряхни телефон. Там можно обновить страницу, вернуть страницу Claude вокруг приложения и сменить ссылку.

## Раз в 7 дней

Бесплатная подпись Apple живёт 7 дней. Включи LocalDevVPN, открой SideStore и нажми **Refresh All**. SideStore умеет делать это и сам в фоне. Комп больше не нужен. Он понадобится, только если после обновления iOS или сброса телефона слетит файл сопряжения (тогда снова iloader).

Новые версии приходят туда же: SideStore → **My Apps → Update**.

## Для друга

Делает те же шаги со **своим** Apple ID и при первом запуске вставляет ссылку на **своё** приложение в Claude.
