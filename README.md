# Gym Tracker для iPhone

Приложение содержит Gym Tracker 12.14, восстановленный из сохранённого экспорта, и прежнюю нативную оболочку iPhone. Для запуска больше не нужны сайт и аккаунт Claude: HTML и изображения входят в IPA.

Сохраняются экраны, упражнения, планы, расчёты, таймер отдыха, Dynamic Island, нативные барабаны и импорт из «Здоровья» через «Команды».

## ChatGPT

Кнопка «Отправить ChatGPT» работает как прежняя «Отправить Claude»: копирует отчёт, который нужно вставить в чат. Для анализа всей истории: Настройки → «Скопировать все данные», затем передать JSON в ChatGPT или Codex.

Это не автоматическая облачная синхронизация с ChatGPT и не встроенный вызов OpenAI API. Подключения к базе Claude в новой версии нет. Нельзя утверждать, что ChatGPT автоматически видит данные телефона.

## Данные и обновление

Данные сохраняются локально; в iPhone-оболочке состояние дополнительно сохраняется в UserDefaults приложения. Bundle ID сохранён: `io.github.fingercomment-dot.gymtracker`. При установке поверх прежней версии тем же Apple ID контейнер приложения должен сохраниться; это необходимо проверить на устройстве. Не удаляйте старое приложение ради обновления.

История старого Claude-артефакта хранится в другом веб-источнике. Автоматический перенос этой истории пока не реализован. Если есть резервный JSON, используйте прежнюю функцию Настройки → «Вернуть данные из копии». Код и сборка не очищают прежние cookies, WKWebsiteDataStore или сохранённую ссылку.

## Сборка и установка

GitHub Actions → Build → Run workflow. В артефактах запуска: `GymTracker-<версия>`, внутри `GymTracker.ipa`. Установка через iloader с прежним Apple ID. Ветки, отличные от main, не публикуют релиз и не меняют источник SideStore.

## Проверки

- `scripts/check-web.cjs`: запуск без Claude, настройки, начало тренировки, восстановление активной тренировки, сохранение и восстановление через нативный мост. Нужны Node, Chrome и пакет `@playwright/test` (или путь в переменной `PLAYWRIGHT_MODULE`).
- `StandaloneUITests`: реальная встроенная страница в iOS Simulator, нативные вкладки, настройки и повторный запуск.
- Существующие UI-тесты сохраняют проверку нативных экранов на демостранице.
